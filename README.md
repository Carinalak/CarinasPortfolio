# Carinas Portfolio 🌸

## Detta projekt är gjort med Vue, Vite och TypeScript. Animationer är gjorda med hjälp av GSAP.
För att köra projektet på din dator, skriv i Terminalen:
- npm i (första gången)
- npm run dev (varje gång)
